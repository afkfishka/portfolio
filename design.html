04 — Кнопки

Шесть состояний, а не два

Hover есть только у мыши. Фокус должен быть виден с клавиатуры. Загрузка не меняет ширину — иначе страница дёргается.

default Основное действие — сплошная заливка акцентом. Второе — контур.
hover Подъём на 1 px, яркость +6%. Только при hover: hover.
active Вниз на 1 px и затемнение — как физическое нажатие.
focus Кольцо 2 px с отступом 2 px. Никогда outline: none без замены.
disabled Прозрачность 38%, курсор not-allowed. Причина должна быть написана рядом.
loading Текст скрыт, но место занимает — ширина не меняется.

10 — Движение

Одна эффектная анимация на страницу

Остальное — микропереходы. Ниже три блока появляются с задержкой 60 ms друг за другом.

Появление

Сдвиг 14 px вверх и прозрачность, 420 ms. Появление — только один раз, при первом входе в экран.

Задержка

Соседние блоки идут через 60 ms. Больше 80 ms — уже «анимация ради анимации».

Отключение

При prefers-reduced-motion движение выключается полностью, контент остаётся на месте.

Никогда: курсор-кружок, прелоадер с процентами, авто-карусель, скролл-джекинг. Ничего из этого не делает сайт дороже — только медленнее.

Как пользоваться

  1. Не изобретать. Нужна кнопка — берётся .ui-btn, а не пишется заново.
  2. Копировать блок целиком вместе с обёрткой и подписью, иначе поедут отступы.
  3. Менять только токены. Цвет, шрифт, радиус — в :root или теме, а не в разметке.
  4. Новый компонент — сначала сюда, в каталог, потом на страницу клиента.
