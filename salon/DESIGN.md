# Дизайн-паспорт — «Флёр», парикмахерский зал

**Статус:** реализация шага 3 готова, ждёт визуальной приёмки владельца. Вариант A выбран; вариант B сохранён отдельно.

| Решение | Значение |
|---|---|
| Ниша / аудитория | Демо парикмахерского зала; вымышленный салон «Флёр», без заявленного города и адреса |
| Арт-направление | Тихая роскошь, как журнальное меню: бумага, чернила, глина |
| Антипример | Розовый градиент, сердечки, салонные клише, три карточки преимуществ, фальшивые отзывы |
| Одно действие | Выбрать свободное время и пройти демонстрационный сценарий записи без звонка |
| Дисплей / текст | Cormorant Garamond 400/500 / Onest 400/500; кириллица; максимум 2 семейства |
| Шкала кеглей | 12 / 14 / 16 / 20 / 28 / 44 / 72 px |
| Палитра | Бумага `#F4F0E8`, чернила `#14100C`, приглушённый `#57503F`, глина `#A4552F`, поверхность `#EDE7DB` |
| Контраст | Чернила/бумага 16,66:1; приглушённый/бумага 7,04:1; глина/бумага 4,71:1; светлый текст/глина 5,11:1; чернила/поверхность 15,38:1 |
| Сетка | Контейнер до 1240 px, поля от 20 px; Hero 7/5, на телефоне одна колонка; список услуг без карточек |
| Радиусы / границы / тени | 0–2 px; линии 1 px; декоративных теней нет |
| Движение | Одно появление заголовка 420 ms; hover подчёркивания 160 ms; всё отключается при `prefers-reduced-motion` |
| Крючок | Свободное окно «сегодня, 18:30»; это симуляция с демо-данными, не реальная доступность мастера |
| Честность | Вымышленные салон, мастера, цены и время будут прямо отмечены как демо; иллюстрации подписаны «иллюстрация»; отзывов и реальных клиентов нет |

## Референсы и компоненты

- `.opencode/skills/web-design/reference/recipes.md` → тихая журнальная подача, бумага/чернила/глина, прайс как меню. Не берём вымышленные цитаты и не выдаём демонстрационные цены за действующий прайс.
- `portfolio/design.html` → выбранная тема salon и подпись к фото. Повторяем только общую палитру/тон, не копируем каталогный экран.
- `portfolio/assets/base.css` → `.ui-menu`, `.ui-photo-frame`, `.ui-btn`, `.ui-input` и focus-visible. Локальная реализация остаётся автономной HTML-страницей.

## Первый экран и результат выбора

Вариант A — журнальный Hero: услуга/CTA слева, один подписанный кадр справа, поверх кадра — компактный слот «сегодня, 18:30». Выбран владельцем: быстрее связывает услугу, атмосферу зала и сценарий записи.

Вариант B — типографическая афиша без фотографии — сохранён в `variant-b.html`. Он легче и выразительнее, но уступает A в наглядности услуги и атмосферы.

## Реализация

- Страница: `index.html`, один файл, общие компоненты из `../assets/base.css` и `../assets/base.js`.
- Шрифты: Fontsource CDN, Cormorant Garamond 400/500 `@fontsource/cormorant-garamond@5.3.0` и Onest Variable `@fontsource-variable/onest@5.3.1`; кириллица, обе лицензии OFL-1.1.
- Единственный локальный визуал — `../assets/salon-thumb.webp`, 800 × 1067 px, 47 952 байта; загружается приоритетно и подписан как иллюстрация.
- Запись — интерактивная локальная демонстрация: услуга + время, доступная клавиатурой; нет полей персональных данных, отправки на сервер или сохранения. Есть проверка пустого выбора и сообщение `aria-live`.
- Цены, имена и время в примере помечены демонстрационными. Реальных адреса, графика, отзывов, компаний и сотрудников нет.
- Контраст: чернила/бумага 16,66:1; приглушённый текст/бумага 7,04:1; глина/бумага 4,71:1; светлый текст/глина 5,11:1; светлая подпись/тёмный блок 8,55:1.
- Проверки: оба варианта на 390 / 768 / 1440 px без горизонтального переполнения; CTA A в первом экране на 390 px (415 px от верха при тестовом viewport 580 px), CTA B также видна (553 px); обе гарнитуры загружены; ноль битых якорей.
- Сценарий записи проверен: пустой выбор показывает человеческую подсказку и фокусирует услугу; выбранные услуга и 19:15 дают локальное подтверждение; данные не записываются в local/session storage.
- Lighthouse для A: доступность 100, best practices 100, SEO 100; ошибок консоли нет.
- Возврат на витрину: первая ссылка в шапке «← Все демо» ведёт на `../index.html`, подчёркнута цветом текста (16,66:1), фокус — рамка 2 px с отступом 2 px. На ≤760 px шапка двухстрочная: бренд и плашка «Демо» сверху, все четыре ссылки — второй строкой; на ≤380 px плашка сокращается до «Демо» (полный текст остаётся для скринридеров). На 320 / 360 / 390 px горизонтального переполнения нет.

## Варианты первого экрана — выбрать до вёрстки

### A — Редакционный кадр с иллюстрацией · рекомендую

```text
┌ ФЛЁР · ДЕМО ───────────────────── меню ┐
│ ПАРИКМАХЕРСКИЙ ЗАЛ     [иллюстрация]   │
│ Стрижка,                              │
│ цвет и уход.          СВОБОДНО СЕГОДНЯ │
│                       18:30 · демо     │
│ [Выбрать время ↗]     [иллюстрация]    │
└ часы/адрес не выдумываем ──────────────┘
```

Слева — спокойный крупный Cormorant, справа — существующий кадр зала или мастера с подписью «иллюстрация» и компактный блок свободного окна. На телефоне сначала заголовок и кнопка, затем иллюстрация/окно. Быстрее объясняет услугу и показывает характер салона; нужен перенос готового WebP из архива в папку проекта и честная подпись.

### B — Типографическая афиша без фото

```text
┌ ФЛЁР · ДЕМО ───────────────────── меню ┐
│ ПАРИКМАХЕРСКИЙ ЗАЛ                     │
│                                       │
│ Стрижка                               │
│ как точка                             │
│ отсчёта.              СЕГОДНЯ · 18:30 │
│                       ОКНО ДЛЯ ЗАПИСИ  │
│ [Посмотреть услуги ↗]                  │
└─────────────────── прайс-линия ───────┘
```

Без фотографий и имитации реальных материалов: почти весь первый экран — типографика, линии и отдельный блок времени. Более авторский и легче по весу; атмосферу салона придётся передавать одной типографикой и композицией.

## Выбор владельца: A

Оба варианта честны и без ложных кейсов. A понятнее за секунду: сразу соединяет парикмахерскую услугу, иллюстративный образ и свободный слот. Встроенный слот — явный демо-сценарий, не обещание реальной записи. B выразительнее, но фраза требует больше внимания и не показывает атмосферу зала.

## Данные, которые остаются демонстрационными

В PLAN указан пример времени 18:30. Любые цены, продолжительность услуг и имена мастеров — только вымышленные значения интерфейса с заметным пояснением «демо-данные». Не придумывать адрес, телефон, график, отзывы или реальную доступность.
