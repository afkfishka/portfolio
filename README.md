# Портфолио

Портфолио включает визитку и три демонстрационные страницы. Компании и данные внутри демо вымышленные.

## Что здесь будет

| Файл | Шаг | Что это |
|---|---|---|
| `design.html` | 1 | Каталог компонентов: 4 арт-направления, шрифты, палитры, кнопки, формы, карточки |
| `assets/base.css` | 1 | Дизайн-система: токены, типографика, сетка, компоненты |
| `assets/base.js` | 1 | Появление при скролле, переключение темы, курсорное освещение с инерцией на устройствах с мышью |
| `index.html` | 2 | Визитка-портфолио |
| `salon/index.html` | 3 | Демо: парикмахерский зал |
| `clinic-bot/index.html` | 4 | Демо: бот для стоматологии |
| `stroyka/index.html` | 5 | Демо: лендинг стройки |
| `screenshots/` | 6 | Три скриншота демо 1280×720 для отправки в Telegram |
| `DESCRIPTIONS.md` | 6 | Короткие двухстрочные описания трёх демо |

Главная использует три WebP-иллюстрации в `assets/`: `salon-thumb.webp`, `clinic-thumb.webp`, `build-thumb.webp`. Они иллюстрируют ниши и не являются скриншотами интерфейсов. Ссылки в карточках ведут на готовые демо.

## Правила

- Каждая страница открывается двойным кликом, без сервера.
- Один файл на страницу, стили — внутри. Общее — только в `assets/`.
- Иллюстрации ниш и общие файлы — в `assets/`; скриншоты интерфейсов — в `screenshots/`.
- Каждая демо-страница подписана «демо», фото — «иллюстрация».
- Рядом с каждой демо — `DESIGN.md`: почему такой шрифт, цвет и крючок. Нужно, чтобы через месяц вы помнили причину.
- Скриншоты `screenshots/*-1280x720.png` сняты с первого экрана при viewport 1280×720.

## Иллюстрации

Файлы `assets/*-thumb.webp` — тематические иллюстрации, а не скриншоты реализованных интерфейсов.
